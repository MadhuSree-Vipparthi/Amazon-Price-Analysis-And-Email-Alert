# Amazon Price Tracker

A Python-based Amazon Price Tracker that monitors product prices and sends email alerts when the price drops below a target value.

## Features

- Scrapes product title and price from Amazon
- Tracks current product price
- Sends email notifications automatically
- Uses Python, BeautifulSoup, Requests, and SMTP

## Technologies Used

- Python
- Requests
- BeautifulSoup4
- SMTP

## How to Run

1. Install dependencies:
   ```bash
   pip install requests beautifulsoup4
   ```

2. Configure your Gmail email and App Password.

3. Run:
   ```bash
   python amazon_price_tracker.py
   ```
